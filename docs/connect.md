# Connect to your server

On first launch Suwa asks for your server:

- **Server address**: the URL you open the Suwayomi web UI at, for example `https://suwayomi.example.com` or
  `http://192.168.1.10:4567`. Plain HTTP is allowed for local servers.
- **Username and password**: only if your server uses basic authentication (Suwayomi's "basic auth" mode).
  Leave them empty otherwise. The login-page modes ("simple login" and "UI login") aren't supported yet.

Tap **Connect**. Suwa checks the address and the login first and saves nothing until the server answers. Change them
later in **More → Settings → Server**.

## Notifications

Android asks whether Suwa may post notifications. Allow it to see download progress and app updates.
